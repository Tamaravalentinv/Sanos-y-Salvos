REPOSITORIO PRINCIPAL DEL PROYECTO
==================================
URL: [Repositorio principal - Sanos y Salvos]
Descripción: Repositorio central que contiene la orquestación completa del 
proyecto, incluyendo Docker Compose, scripts de deployment, configuraciones 
de entorno, y referencias a todos los componentes.
Contenido:
  - docker-compose.yml (orquestación de servicios)
  - Dockerfile.base (imagen base para contenedores)
  - Scripts de deployment (up.sh, down.sh, health-check.sh)
  - Configuración de base de datos (docker/init/)
  - Documentación general del proyecto


REPOSITORIOS DE COMPONENTES
===========================

1. FRONTEND
-----------
URL: [frontend - Sanos y Salvos]
Ubicación Local: /frontend
Descripción: Aplicación web desarrollada con React + TypeScript + Vite.
Interfaz de usuario para el sistema de reportes y geolocalización.
Contenido:
  - Componentes React reutilizables (Button, Card, Input, Select, etc.)
  - Páginas principales (Dashboard, Reportes, Mensajes, Notificaciones, etc.)
  - Servicios API client (api.client.ts, auth.service.ts, etc.)
  - Contexto global de estado (authStore, mensajeStore, notificacionStore)
  - Configuración de Tailwind CSS y Vite
  - Tipos TypeScript centralizados
Tecnología: React 18+ | TypeScript | Vite | Tailwind CSS


2. BFF - BACKEND FOR FRONTEND
-----------------------------
URL: [api-gateway - Sanos y Salvos]
Ubicación Local: /api-gateway
Descripción: Backend For Frontend que actúa como puerta de entrada única
para el frontend. Realiza composición de servicios, orquestación y agregación
de datos provenientes de los microservicios.
Contenido:
  - Código fuente Java/Spring Boot
  - Controladores REST para endpoints del frontend
  - Lógica de composición y orquestación
  - Cliente HTTP para comunicación con microservicios
  - Configuración de seguridad y autenticación
  - Dockerfile para containerización
Tecnología: Java | Spring Boot | Maven
Puerto: 8080


3. MICROSERVICIO: MS-AUTENTICACION
------------------------------------
URL: [ms-autenticacion - Sanos y Salvos]
Ubicación Local: /ms-autenticacion
Descripción: Microservicio responsable de autenticación, autorización y
gestión de usuarios. Maneja tokens JWT, permisos de rol y acceso a recursos.
Contenido:
  - Lógica de autenticación (login, registro, validación)
  - Gestión de usuarios y roles
  - Generación y validación de JWT
  - Controladores REST para endpoints de autenticación
  - Bases de datos de usuarios
Tecnología: Java | Spring Boot | JWT | Maven
Puerto: [Configurado en application.properties]


4. MICROSERVICIO: MS-GEOLOCALIZACION
--------------------------------------
URL: [ms-geolocalizacion - Sanos y Salvos]
Ubicación Local: /ms-geolocalizacion
Descripción: Microservicio que maneja toda la funcionalidad de geolocalización.
Registra ubicaciones de usuarios, calcula distancias, y proporciona servicios
de mapeo geográfico para el sistema de reportes.
Contenido:
  - Lógica de geolocalización
  - Cálculo de coordenadas y distancias
  - APIs de mapeo
  - Integración con servicios de GPS
  - Almacenamiento de datos de ubicación
Tecnología: Java | Spring Boot | GIS APIs | Maven
Puerto: [Configurado en application.properties]


5. MICROSERVICIO: MS-REPORTES

URL: [ms-reportes - Sanos y Salvos]
Ubicación Local: /ms-reportes
Descripción: Microservicio central para la gestión de reportes médicos

  - Validación de datos de reportes
  - Almacenamiento de reportes

Tecnología: Java | Spring Boot | MySQL | Maven
Puerto: [Configurado en application.properties]

ARQUETIPOS MAVEN
=================
URL: [sanos-microservice-archetype - Sanos y Salvos]
Ubicación Local: /sanos-microservice-archetype
Descripción: Archetype Maven que proporciona una plantilla base para crear
nuevos microservicios siguiendo los estándares del proyecto Sanos y Salvos.
Incluye estructura de carpetas, dependencias comunes, y configuraciones
predefinidas.
Contenido:
  - Estructura de proyecto Maven base
  - Dependencias estándar (Spring Boot, JUnit, etc.)
  - Configuración de application.properties
  - Dockerfile plantilla
  - Clases base y controladores de ejemplo
  - POM.xml configurado

Uso: mvn archetype:generate -DarchetypeGroupId=... -DarchetypeArtifactId=sanos-microservice-archetype

NOTAS GENERALES
================================================================================

1. ESTRUCTURA DE REPOSITORIOS:
   - Cada componente puede estar en su propio repositorio Git individual
   - O pueden estar organizados en un monorepo con este repositorio principal

2. CONVENCIONES DE PUERTO:
   - BFF (api-gateway): 8080
   - Microservicios: Configurados individualmente en application.properties
   - Frontend: Puerto local configurado en vite.config.ts

3. CONFIGURACION DE AMBIENTE:
   - Todos los microservicios se despliegan mediante docker-compose.yml
   - Las credenciales de BD están en docker/init/01-create-databases.sql

4. DOCUMENTACION ADICIONAL:
   - Cada componente contiene su propio README.md con instrucciones específicas
   - Ver ANALISIS_PATRONES_ARQUETIPOS.md para patrones de arquitectura
   - Ver PLAN_BRANCHING.md para estrategia de ramas Git
